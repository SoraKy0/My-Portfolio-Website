# Portfolio Website

An interactive personal portfolio site styled as a traditional Japanese shop.

## Live Site



## About

I wanted to create something more personal and fun than a typical portfolio website, so I built an interactive experience inspired by Japanese shop interiors.

Instead of a generic layout, the site uses interactive elements to showcase my projects, skills, and interests.
